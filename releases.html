Index · Versions

Every release, on the record

Each BAS Hub release ships with structured patch notes — a plain-language summary and the full notes — bundled into the product itself, so they read offline. This page carries the same record. Version numbers are semantic for the suite: a new module class or breaking change moves the major, new features move the minor, fixes move the patch.

How versions are supported. No public release exists yet — the first public release is in preparation. Once releases begin: the latest release is the supported one. Previous releases stay downloadable permanently as legacy builds — unsupported, kept for reference and rollback — and when a newer release fixes a known defect in an older one, the older release's entry says so plainly. The app itself only ever offers the latest release in its update check. 1.0.0 is reserved for the first release proven end-to-end in the field; the 0.9.x line is the pre-1.0 line.

0.9.1

Internal build — not a public release Built 2026-10-20

BAS Hub 0.9.1 — installs you can watch, failures you can hand over

Not publicly downloadable. 0.9.1 was published briefly on 2026-10-20 and withdrawn the same day by the owner’s decision — the build was not appropriate as a live release. It is held as an internal build; its notes below are the record of what the build contained. A Windows ARM64 package exists as a candidate build and is not published until it is verified on ARM64 hardware.

  • Installing now shows real percentages: an overall number for the whole install and, under the bar, the current step's own numbers — files done out of files total, megabytes downloaded out of the model's size. Every number is computed from the work itself, so a moving number means real progress.
  • If anything goes wrong anywhere in BAS Hub, you get a popup that explains it in plain language — what happened, what it means, what to do — with an Open log folder button and a Close button. (If the app itself froze, the popup offers Close and relaunch instead.) The same moment, a log file is saved that you can hand to whoever helps you.
  • Fixed: installing on Windows could stop at the final step with an "access denied" message naming the staging folder. Nothing was ever half-installed and no data was touched; this release removes the cause in the code and hardens the whole final step.
  • The download is now one file. Setup carries everything inside itself and checks its own contents before installing — there is no folder of files to keep together. Before an install or an update, Setup first shows the License Agreement together with the User Guide's table of contents and its Read me first section; one checkbox, and the install record keeps what was accepted, when, and how.
  • The full User Guide now ships with BAS Hub: the PDF sits beside the installer and is installed with the app, and Help → User guide opens the same book inside the app — same chapters, same pictures, one source.
  • Settings is filled in: your data folder, safety backups with a keep-count and sizes, a Back up everything export, a diagnostics bundle for support, proxy settings, BACnet defaults, a start-page choice, and Copilot model management. Settings also ends with an About section — versions at a glance and a Copy version info button for bug reports.

The full section-by-section notes — install percentages, the failure popup and logs, the Windows install fix, the License Agreement gate, the settings bundle, protection, and the named known shortfalls — are bundled inside the app (Help → Release notes). There is no download for this build — see Download for the first public release, in preparation.

0.9.0

Internal first build — not a public release Built 2026-10-19

BAS Hub 0.9.0 — the suite, in one app

Not publicly downloadable — by design. 0.9.0 is the internal first build. It never published; 0.9.1 supersedes it. Its notes below are the record of what the first build contained.

  • BAS Hub is one app for controls work. Programmer+ and Network+ live side by side on one home screen and share one device inventory, so a device you find in Network+ is the same record everywhere.
  • Programmer+ is rebuilt inside the Hub: a PPCL editor that checks as you type, block diagrams, decision tables, a simulator and debugger, the point database, and the code library.
  • Network+ starts from jobs in plain language — find what's on this network, look at a device, watch traffic, check the network's health, prove a loop works, talk to a device, and see what changed since last time.
  • BAS Copilot is an optional assistant that runs entirely on your computer. It is off unless you choose it during install, and it never sends your data anywhere.
  • If BAS Hub ever crashes, it saves a plain-language crash report on the computer and tells you about it on the next launch. Nothing is ever sent automatically.
  • Updates are yours to start: Settings has a Check for updates button. BAS Hub never checks, downloads, or installs anything on its own.

The full notes, as bundled with the product:

The Hub home

  • Your installed modules are tiles under Built-in Modules. Your own categories and shortcuts to other programs sit below them and can be rearranged by dragging.
  • BAS Copilot, when installed, is the icon at the top right. Settings is beside it, and the File / Modules / View / Help menu strip is at the top left.
  • There is no "active site" to pick. Sites appear only when you save or back something up, as a "Save to a site" option.

Programmer+

  • Editor with checks as you type and a findings panel that explains each finding — why it matters, the fix, and the manual page it comes from.
  • Block diagrams and decision tables that compile to PPCL, with plain-language refusals when something cannot compile.
  • Simulator and debugger: run a program against a plant, compare runs, scrub back through recorded passes, set breakpoints and watch points.
  • Point database, start/stop time optimization, vendor imports, and a code library that converts between text and blocks.
  • Programmer+ carries its own 21-topic help, available inside the module.

Network+

  • Find: discover what is on the network — BACnet, Modbus, and OPC UA devices land in the shared inventory.
  • Look: one page per device with its points and values.
  • Watch: capture traffic and read it back decoded in plain words, with a truth check from the capture's own counters.
  • Health: the full diagnostics catalog with a three-part health score that always expands into the findings behind it, plus "Why is this device offline?" evidence runs.
  • Prove: a test bench for checkout plans and changes. Every write goes preview, backup, confirm, verify — and can be rolled back.
  • Talk: a real terminal for SSH, Telnet, and serial sessions, prefilled from the device record.
  • Records: what changed since last time, baselines with drift, and hashed exports that re-verify every file.

BAS Copilot

  • Optional at install. Setup checks your computer first and only offers model sizes it can run well; bigger sizes stay locked with the reason in plain language.
  • Runs entirely on your computer. No account, no cloud, nothing phones home; the one download is the model file at install, verified against its checksum.
  • It can explain and draft, never act: no device writes, no sends, no file changes come from the assistant.

Installing and changing modules

  • You choose the install location. Your data stays in the standard data folder wherever the program lives.
  • Run Setup again on an installed computer and it opens a maintenance screen instead: Update, Change modules, and Uninstall.
  • The Npcap packet-capture driver is offered inside the Network+ choice — Capture needs it — and installs from its own signed installer.
  • Uninstall removes exactly what the install record lists. Your data is kept unless you explicitly choose "also remove my data".

The release payload carries three modules (programmer-plus, network-plus, bas-copilot) and four Copilot model tiers. Installs are staged and committed as one move, so a failed install leaves the previous state untouched.

Reliability

  • Crash reports are structured files kept on the computer — the last 10, size-capped, with secrets kept out — and the next launch says in plain language that one was saved and offers to open the folder.
  • Multi-step operations are transactional in effect: nothing half-installs, and every device write is backed up before it happens.

The full automated verification harness passed 849 of 849 checks against this release's sources, including the write-safety loop against a test device and a full silent install, receipt audit, and uninstall cycle.

Known shortfall, stated in the notes themselves: 0.9.0’s update check looks for a published release manifest; none is published, so the check reports that plainly and changes nothing. (0.9.0 also embeds the pre-rotation trust key, so it could not accept a current manifest in any case, by design for a superseded internal build.)

There is no download for this build — see Download for the first public release, in preparation.
