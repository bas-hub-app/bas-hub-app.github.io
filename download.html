Install

Run the installer for your platform. It installs per user, in a location you choose, and needs no administrator rights. The one exception: packet capture in Network+ uses the Npcap driver — if you choose it, Npcap's own signed installer runs and prompts for elevation.

An install is staged and committed as one move: a failed or cancelled install leaves the previous state untouched. Every install writes a receipt, install.json, into the install folder — every installed file with its SHA-256, the modules chosen, and the Copilot tier if one was installed.

Your data lives in %LOCALAPPDATA%\BAS Hub\data on Windows (the matching per-user data folder on Linux) and is never removed by updating or uninstalling. Uninstalling removes the program files the receipt lists and reports the result: if some files cannot be removed, they stay on disk and the result says so. Adding /purge to an uninstall removes the data folder as well.

Silent install and scripting

Setup accepts command-line switches for scripted deployment. A silent install with no module switches installs the same set as the interactive default — every module, BAS Copilot included, with the model tier this computer can run. Naming modules in /modules= narrows the set, and a Copilot model downloads only when /ai is given.

SwitchWhat it does
/silentInstall without the interactive wizard. Terms are accepted with /accept-terms.
/modules=<list>Comma-separated module ids to install.
/ai=auto or /ai=<tier>Download and install a Copilot model tier: helper, standard, solid or workshop. Without it, no model is downloaded.
/npcapInclude the Npcap packet-capture driver step.
/target=<path>Install location.
/update-checkReport whether a newer release exists; exit code 8 means one is available.
/verifyVerify the installed files against the receipt.
/uninstallRemove the program files the receipt lists; data is kept.
/purgeWith an uninstall, also remove the data folder.

Exit codes

0 success · 1 error · 2 not installed · 3 bad arguments · 4 payload checksum mismatch · 5 downgrade refused · 6 cancelled · 7 verification failed · 8 update available (with /update-check) · 9 updates disabled by policy · 11 apply refused: BAS Hub is running. Code 10 is not used.

Updates

BAS Hub does not update itself in the background. An optional check at launch — off by default, turned on in Settings — reads the latest stable release and tells you when a newer build exists. Downloading and applying an update are manual, here or in the app.

When an update applies, the previous version is kept until the new one has launched once. If an apply fails partway, the install can be left mixed, with no automatic revert — reinstalling from this page is the remedy.

Moving from 0.9.5, 0.9.6 or 0.9.7, the in-app update path works. Moving from 0.9.3 or 0.9.4, use the standalone installer from this page: the in-app download step in those versions crashes (fixed in 0.9.5).
