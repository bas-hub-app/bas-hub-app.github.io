What happens next

Reports are reviewed against the product as shipped and answered on the issue, in the open. Fixes land in a later build and are named in its release notes. Support is best-effort — there is no promised response time.

Questions

  • Is BAS Hub open source?

    No. BAS Hub is proprietary software. The releases repository holds installers, the user guide and the software bill of materials — it will never contain source code.

  • Does BAS Hub work offline?

    Yes. Everything runs locally. A connection is made only for an action you start: an update check, or a Copilot model download. Copilot models can be pre-staged beside the installer and are hash-verified, which is the offline route for a site with no internet.

  • Does it need administrator rights?

    No. BAS Hub installs per user; the Download page’s Install section covers the one exception, an optional driver.

  • Can Copilot change anything on a device?

    Copilot itself never writes to a device — it explains and drafts only. Device writes exist in Network+ and in TBC+, each behind its own confirmation and proof steps, and are made by the person running the module, not by the assistant.

  • What does Copilot do with my data?

    Inference runs on your own computer; there is no telemetry. The only network moment is a model download you start, verified against its SHA-256 before use. Chat history is stored locally and deletes in one click. If Copilot is not installed, there is no chat or AI surface anywhere in BAS Hub.

  • How much should I trust Copilot’s answers?

    Check its work the way you’d check a junior tech’s. It works from your own material, but an answer can be wrong; the modules show their evidence so you can verify before you act.

  • Where does my work live?

    Settings and logs live in the data folder (%LOCALAPPDATA%\BAS Hub\data on Windows). Work you file lives in My Files & Library, organised by site. Device records stay in a module’s working set until you file them. Updating or uninstalling never removes the data folder; an uninstall with /purge does.

  • Something failed. What should I send?

    Settings → Open logs folder takes you to BAS Hub’s logs. The log from the run where it happened carries the diagnostics, and it is the single most useful thing you can attach to a bug report.

  • Can I deploy BAS Hub silently across machines?

    Yes. Setup’s command-line switches and exit codes are listed on the Download page — including which modules a silent install includes and when a Copilot model downloads.

  • Does Programmer+ download programs to panels?

    No. Programmer+ is an authoring workbench — editor, builder, library, simulator. It never communicates with a panel.

  • What can Reports+ produce?

    Sixty report subjects over filed records and module output, for three audiences, with mechanical redaction. The full catalogue is on the Reports+ page.

  • What do the version numbers mean?

    0.9.9 is the current pre-1.0 line; its builds are numbered by iteration, and iteration 9 is the current build. 1.0.0 is reserved for the first release proven end-to-end in the field.
